Entry for the [make.fun](https://make.fun) competition
**The Printer Finally Answers** (`u-mang-the-printer-finally-answers-8fbf0907`).

`main.ts` writes one line — the office printer's comeback to the paper jams,
the cryptic error codes, and the thumps — to `/output/entry.txt`
(`MAKEFUN_OUTPUT_DIR` when set). The line is gated to 1–240 characters and is
deterministic: the same bytes on every run.

```sh
node main.ts
```
